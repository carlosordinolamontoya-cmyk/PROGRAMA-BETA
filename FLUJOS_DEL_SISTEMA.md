# Flujos del sistema

## Flujo de almacén

Ingreso CN → Stock aumenta → Vale Word → Reportes valorizados.

Salida CO → Valida stock → Stock disminuye → Costo valorizado → Consumo por CC/OT.

Transferencia → Vale salida origen + vale ingreso destino + guía.

## Flujo de requerimiento

Requerimiento → Atención con stock o generación de OC → OC activa bloquea nuevo uso del requerimiento → Recepción/atención.

## Flujo de orden de compra

OC pendiente → Aprobación total/parcial → Pago contado/crédito → Tránsito → Recepción almacén → Liquidación.

## Flujo financiero

OC aprobada → Por pagar → Pago parcial/Pagada → Aging y trazabilidad.

## Cierre mensual

Valorización mensual → Cierre del periodo → Bloqueo de movimientos antiguos → Ajustes solo por ADMIN.
