# Manual de usuario - Finanzas

## Pagos

1. Entrar a Finanzas > Seguimiento de pagos OC.
2. Buscar OC por número, proveedor o RUC.
3. Registrar pago con fecha, banco, número de operación, número de factura, monto y observación.
4. El sistema bloquea pagos que superan el saldo.
5. El sistema bloquea pago duplicado por banco, operación y monto.
6. El sistema bloquea factura duplicada para el mismo proveedor.

## Aging / cuentas por pagar

Usar Control ERP > Cuentas por pagar / Aging para filtrar:

- Por vencer.
- Vencidas.
- Pagadas.
- Pago parcial.
- Proveedor.
- Moneda.
