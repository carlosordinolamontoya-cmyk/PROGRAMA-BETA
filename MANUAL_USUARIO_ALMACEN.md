# Manual de usuario - Almacén

## Flujo recomendado

1. Registrar artículo o cargar maestro de artículos.
2. Registrar ingreso manual CN cuando se recibe material sin OC.
3. Registrar salida CO para consumo por OT o centro de costo.
4. Usar Transferencia entre almacenes para movimientos AQP ↔ MIN con número de guía.
5. Atender requerimientos cuando exista stock.
6. Registrar entrada con OC cuando logística haya aprobado una orden de compra.
7. Consultar o imprimir vales desde Almacén > Consultar Vale.
8. Reversar vales solo con motivo obligatorio.

## Periodos cerrados

Cuando un mes se cierre, no se podrán registrar movimientos anteriores. Solo un ADMIN podrá registrar ajustes autorizados.
